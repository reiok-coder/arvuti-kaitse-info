Personal desktop backup tool

Encrypted backups in your own Google Drive.

Arvuti-kaitse copies selected local backups from a personal computer to a separate encrypted repository in the computer owner's Google Drive.

The tool runs on the owner's computer and uses restic for encrypted backup storage and rclone for the Google Drive connection. The owner chooses the local data to protect and controls the backup schedule, retention and recovery password.

What Google Drive access is used for

The tool requests only the https://www.googleapis.com/auth/drive.file permission. It creates and manages its own backup files and folders. This permission also permits access to files a user explicitly makes available to the app; Arvuti-kaitse uses it for its backup repository.

The connection supports uploading encrypted backup objects, listing and checking that repository, downloading objects for restoration, checking available storage and removing obsolete backup objects under the owner's retention settings.

Under the owner's control

File contents and backup metadata are encrypted on the computer before upload. The recovery password stays outside Google Drive. Google authorization tokens are kept in a private local configuration file so scheduled backups can run.

The owner can stop the scheduled tasks and revoke access in their Google Account connections. Revoking access stops future authorized operations; existing backup objects remain in Drive until the owner deletes them.

This website describes the tool. It does not sign users in or receive backups. Arvuti-kaitse is a self-managed personal utility, with no public account registration or hosted backup service.
